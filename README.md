# Frog at Dusk: Nightfall Survival

A 3D grid-hopping survival game built with Three.js and Vite, extending the JetBrains Academy course project *Build a Game with an AI Coding Agent*. Guide the frog through 1 minute of daylight, 1 minute of sunset and 2 minutes of night, then survive until daylight to win. See [game.md](game.md) for the full feature overview.

## Build and run

Requires Node.js 18+.

```bash
npm install
npm run dev      # development server (prints a local URL)
npm run build    # production build into dist/
npm run preview  # serve the production build
```

## Controls

| Key | Action |
| --- | --- |
| Arrow keys | Queue grid-aligned hops |
| Space | Defensive attack (also starts/restarts a run) |

The sound toggle and Easy / Normal / Hardcore difficulty selection are on the title screen.

## What was added to the original course project

- Day, sunset and night cycle that changes sky, fog, lighting and map colors
- Rocks, trees, houses and ponds as obstacles (ponds slow enemies and ripple when crossed)
- Collectible fireflies and gifts: shield, cloak, score boost, Moon Jump, Pond Leap
- Four enemy types: chaser, wanderer, ambusher, night seeker
- Three lives, hit feedback, win condition (survive to daylight)
- Achievements, challenges, lifetime analytics, best score (local storage)
- Post-run upgrade store (extra heart, longer reach, gift duration) funded by fireflies
- Easy / Normal / Hardcore modes
- Responsive HUD, title and game-over screens; original Web Audio sound effects

Details: [game.md](game.md).

## AI tools used

- **GitHub Copilot** (GPT models) wrote most of the later game systems and sourced the extra 3D models; **ChatGPT / Codex** built the first extension batches (day/night cycle, obstacles, pickups, HUD, progress tracking); **Claude** was used occasionally for help and documentation.
- The 3D models were not generated by AI tools; the AI agents only downloaded and wired them in (see below).
